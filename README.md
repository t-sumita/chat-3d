# Chat 3D

ブラウザだけで完結する、**テキスト指示 / コード実行による 3D モデル(STL)生成・編集ツール**の PoC です。
バックエンドはありません。すべて HTML / CSS / Vanilla JavaScript で動きます。

🔗 **公開版:** https://t-sumita.github.io/chat-3d/

## 3 つの使い方

| モード | 概要 |
| --- | --- |
| **STL 編集** | STL / 3MF ファイルをプレビュー領域に **ドラッグ&ドロップ**し、チャット指示で穴あけ・結合などの CSG 加工を行う。3MF は形状のみ読み込み、色情報は無視される。 |
| **ゼロベース生成** | STL を読み込まず、チャット指示だけで Box / Cylinder / Sphere などの基本図形 + CSG からモデルを生成する。 |
| **直接編集(チャット不要)** | 「編集」タブで、拡大縮小・消しゴム・パーツ分割・図形/文字の追加をマウスと数値入力だけで行う。 |
| **マニュアルコード実行** | ChatGPT 等で作った JavaScript を「コード」タブに貼り付け、「STL反映実行」でシーンに反映する。 |

「STL ダウンロード」ボタンで、現在のメッシュをいつでもバイナリ STL として保存できます。

## チャットの 2 つのモード

「チャット」タブでは、LLM とのやりとり方法を **コピペモード** / **API モード** の 2 種類から選べます。

| モード | 概要 |
| --- | --- |
| **📋 コピペモード**(既定) | ChatGPT / Claude など、**Gemini に限らず好きな LLM** とチャット欄外で直接やりとりする方式。①「プロンプトをコピー」でシステムプロンプト+指示をクリップボードにコピー → ②外部チャットに貼り付けて送信 → ③返ってきた回答を「外部チャットの回答を貼り付け」欄に貼って「貼り付けを実行」。この手順はチャットログにガイドとして自動表示されます。API キー登録は不要です。 |
| **🔌 API モード** | 設定タブに登録した Gemini API キーを使い、指示の送信からコード実行までを自動で行う方式。 |

## 「編集」タブ — チャットを使わない直接操作

LLM に頼らず、その場で形を直せます。すべての操作はヘッダの **↶ / ↷**(Ctrl+Z / Ctrl+Y)で元に戻せます。

| 機能 | 内容 |
| --- | --- |
| **拡大・縮小** | 全体倍率 / XYZ 個別倍率 / 目標寸法(mm)の直接指定(比率保持の切替あり)。 |
| **消しゴム** | ON にしてモデルをクリックすると、その位置を指定半径の球で削る。視点のドラッグ回転とは自動で区別される。 |
| **パーツ分割** | つながっていない塊(板・部品など)を自動認識して一覧化。選んだパーツだけを拡大縮小・削除できる。 |
| **図形の追加** | 直方体 / 円柱 / 球 / 円錐を、サイズと位置(mm)を指定して**結合**または**削り取り**。 |
| **テキスト** | 立体文字を追加 / 彫り込み。**半角英数字・記号のみ**(日本語フォントは未対応)。 |

> パーツ分割は、頂点座標を量子化して溶接し Union-Find で連結成分を求めています。STL のように
> 頂点が重複した形式でも正しく分割できます。モデルを変更すると一覧は解除されるので、再度「分割」を押してください。

> undo 履歴はジオメトリの実体を保持するため、段数を 12 に制限しています。

## ⏱ 重い処理と実行前ガード

CSG（ブーリアン演算）は**三角形数が増えるほど急激に遅くなり、しかも結果の三角形数を増やします**。
そのため加工を重ねるほど次の処理が重くなり、「1 回目は成功したのに 2 回目で固まる」ことが起こります。

計算はメインスレッドを占有する同期処理なので、**開始したら中止できません**。
ブラウザが「ページが応答しません」と表示した場合は **「待機」** を選べば処理は続きます。
（`RESULT_CODE_HUNG` の画面まで出てしまうと、そのタブの作業内容は失われます。）

これを踏まえ、実行前に規模をチェックします。

| 対象の三角形数 | 挙動 |
| --- | --- |
| 〜20,000 | そのまま実行。 |
| 20,000〜60,000 | 実行し、オーバーレイで「中止できない・数分かかる場合がある」旨を強調表示。 |
| 60,000 超 | **実行前に確認ダイアログ**を出す。所要時間の見積り・失敗の可能性・STL 保存の推奨を表示し、「それでも実行する」を選んだときだけ進む。 |

対象は「コード」タブの実行と、「編集」タブの CSG 操作（消しゴム / 図形の結合・削り取り）です。
実行後の「実行レポート」には**三角形数の増減**と、次回の実行が重くなる旨の警告が出ます。

あわせて、システムプロンプトで LLM 側にも三角形数の抑制を依頼しています
（分割数を控えめに指定する / CSG の回数を最小にする / 移動・回転・拡大縮小に CSG を使わない）。
現在の三角形数も LLM に渡すので、重い状態なら LLM 側がさらに保守的な生成に切り替えます。

> 現状、作業内容の自動保存はありません。**区切りごとに「STL 保存」でバックアップしてください。**

判明している制約・未対応事項は [`docs/known-issues.md`](./docs/known-issues.md) にまとめています。

## 使いはじめ

1. リポジトリを開く（ローカルなら任意の静的サーバで配信）。
   ```bash
   # 例: Python の簡易サーバ
   python -m http.server 8000
   # → http://localhost:8000/ を開く
   ```
   > `importmap` と ES Modules を使うため、`file://` 直開きではなく **HTTP 配信**が必要です。
2. **API モードを使う場合のみ**、「設定」タブで Gemini API キーを入力
   （[Google AI Studio](https://aistudio.google.com/app/apikey) で取得）。
   キーは **ブラウザの localStorage にのみ保存**され、Subutomo のサーバには送信されません。
   コピペモードならキー登録は不要です。
3. チャットに日本語で指示するか、STL / 3MF を D&D して編集を始めます。

### 指示の例（ゼロベース生成）
- 「一辺 40mm の立方体の中心に、直径 20mm の貫通穴をあけて」
- 「外径 30mm・内径 20mm・高さ 15mm のパイプを作って」

### 指示の例（STL 編集）
- 「上面の中央に直径 10mm の穴を深さ 5mm であけて」
- 「全体を 1.2 倍に拡大して」

## 技術スタック
- **3D 描画:** [Three.js](https://threejs.org/) r160（CDN + importmap）
- **ブーリアン演算:** [three-csg-ts](https://github.com/samalexander/three-csg-ts) 3.2.0
- **LLM:** Gemini API（REST、ブラウザから直接呼び出し）

依存はすべて CDN から解決するため、**ビルド不要**。`index.html` を静的配信するだけで動きます。

## 動的コード実行の契約
チャット/コード直接入力で実行される JS には、次が引数として渡されます。

| 変数 | 内容 |
| --- | --- |
| `scene` | 表示中の `THREE.Scene` |
| `THREE` | Three.js 名前空間 |
| `CSG` | three-csg-ts の `CSG` クラス（`union` / `subtract` / `intersect`） |
| `targetMesh` | 現在の操作対象メッシュ（無ければ `null`） |
| `setResult(mesh)` | 完成メッシュを 1 つ登録する関数 |

- 完成メッシュは必ず `setResult(mesh)` で登録します（`scene` への add は不要）。
- CSG 演算の前に、関与する各メッシュで `mesh.updateMatrix()` を呼んでください。

```js
// 立方体に貫通穴をあける例
const box = new THREE.Mesh(new THREE.BoxGeometry(40, 40, 40));
const hole = new THREE.Mesh(new THREE.CylinderGeometry(10, 10, 60, 32));
box.updateMatrix();
hole.updateMatrix();
setResult(CSG.subtract(box, hole));
```

## ⚠ セキュリティに関する注意
本ツールは指示された JavaScript を `new Function` で**そのまま実行**します。これは本質的に
任意コード実行であり、PoC としての利便性を優先した設計です。**信頼できないコードを貼り付けて
実行しない**でください。第三者に公開・共有する用途は想定していません。
