Chat 3D について

ブラウザだけで完結する、テキスト指示 / コード実行による 3D モデル(STL)生成・編集ツールの PoC です。バックエンドは持ちません。

  • STL 編集 — STL/3MF を Drag&Drop で読み込み、チャット指示で CSG 加工(穴あけ・結合など)。
  • ゼロベース生成 — 何も読み込まずチャット指示だけで基本図形 + CSG から生成。
  • コード直接入力 — 外部 LLM で作った JavaScript を貼り付けて実行。

CSG とは?

立体どうしを「足す・引く・重なりを取る」演算のことです。たとえば立方体から円柱を「引く」と、そこに穴が開きます。3D プリンタ用のモデルを組み立てるときの、いちばん基本になる操作です。

  • 結合(union) — 2 つの立体をくっつけて 1 つにする。
  • 削除(subtract) — 片方の立体で削り取る。穴・溝・切り欠きはこれ。
  • 交差(intersect) — 重なっている部分だけを残す。

単位と座標

数値は mm として扱います(40 と書けば 40mm)。読み込んだモデルは原点が中心になるよう自動で移動されるので、「中心から 20mm 右」のように指示できます。

⚠ 貼り付けたコードは、中身を検査せずそのまま実行されます。何が書かれていても実行されてしまうため、出どころの分からないコードは貼り付けないでください。
