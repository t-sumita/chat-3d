Chat 3D について

ブラウザだけで完結する、テキスト指示 / コード実行による 3D モデル(STL)生成・編集ツールの PoC です。バックエンドは持ちません。

  • STL 編集 — STL/3MF を Drag&Drop で読み込み、チャット指示で CSG 加工(穴あけ・結合など)。
  • ゼロベース生成 — 何も読み込まずチャット指示だけで基本図形 + CSG から生成。
  • 編集 — チャットを使わず、拡大縮小・消しゴム・パーツ分割・図形/文字の追加をマウスと数値で直接操作。
  • コード直接入力 — 外部 LLM で作った JavaScript を貼り付けて実行。

CSG とは?

立体どうしを「足す・引く・重なりを取る」演算のことです。たとえば立方体から円柱を「引く」と、そこに穴が開きます。3D プリンタ用のモデルを組み立てるときの、いちばん基本になる操作です。

  • 結合(union) — 2 つの立体をくっつけて 1 つにする。
  • 削除(subtract) — 片方の立体で削り取る。穴・溝・切り欠きはこれ。
  • 交差(intersect) — 重なっている部分だけを残す。

単位と座標

数値は mm として扱います(40 と書けば 40mm)。読み込んだモデルは原点が中心になるよう自動で移動されるので、「中心から 20mm 右」のように指示できます。

保存した STL をスライサーで開くとき

CSG(穴あけ・結合など)を重ねると、見た目は変わらなくても三角形の数だけがどんどん増えていきます。そのため Bambu Studio などのスライサーで開いたときに「三角形が多すぎる」という警告が出ることがあります。

そこでスライサー側の「簡略化(Simplify)」機能で三角形を大まかに減らすと、モデルに穴が開いて壊れることがあります。単純に間引く処理は、閉じた立体(水密)としての整合性まで見てくれないためです。

  • 警告が出ても、そのままスライスできる場合は簡略化しないのが一番安全です。
  • 減らしたい場合は、雑な簡略化ではなく「修復(Repair)」機能があるツール(Bambu Studio の右クリックメニューの修復、Meshmixer、Netfabb など)を先に試してください。
  • 穴が開いてしまった場合も、多くのスライサーには自動修復機能があります(今回のように「モデルオブジェクトを修復中」と出るのがそれです)。
  • そもそも三角形を増やさないよう、この chat-3d 側でも指示や設定を工夫しています(分割数を控えめにする・CSG の回数を減らす、など)。

「面が欠けている」と言われたときの使いこなし

スライサーで開いたときに少しだけ面が欠けていることがあります。CSG は形を切り貼りする過程で三角形を細かく分割するため、その境目にごく小さな隙間や、面積がほぼゼロの三角形が残ることがあるためです。chat-3d の不具合というより、この方式に付いてまわる副作用だと考えてください。

スライサーの修復(Repair)機能で、たいていは印刷できる状態になります。ただしここが使いこなしの分かれ目です。

  • ⚠ 修復は「意図して作った部分」まで消すことがあります。細い突起・薄い板・小さな穴などは、修復する側から見ると「壊れた部分」と区別がつきません。
  • 修復の前後で形を見比べてください。特に細部が消えていないかを確認します。
  • 修復前の STL を別名で残しておくと、消えすぎたときにやり直せます。
  • 細部が消えてしまう場合は、修復に頼らずchat-3d 側で作り直すほうが早いことが多いです。細い部分を太く(目安 1.5mm 以上)、小さすぎる穴はやめる、といった指示で作り直してください。
  • 穴は「貫通させて」と指示するほうが安全です。切り取る側の形が相手の面とぴったり重なると隙間が生まれやすいため、少しはみ出させて切り抜くよう chat-3d 側でも LLM に指示しています。

なお、簡略化(Simplify)は修復とは別物です。簡略化は穴を増やす方向に働くので、面が欠けているときに使わないでください。

⚠ 貼り付けたコードは、中身を検査せずそのまま実行されます。何が書かれていても実行されてしまうため、出どころの分からないコードは貼り付けないでください。
