Chat 3D について

ブラウザだけで完結する、テキスト指示 / コード実行による 3D モデル(STL)生成・編集ツールの PoC です。バックエンドは持ちません。

  • STL 編集 — STL/3MF を D&D 読み込みし、チャット指示で CSG 加工(穴あけ・結合など)。
  • ゼロベース生成 — 何も読み込まずチャット指示だけで基本図形 + CSG から生成。
  • コード直接入力 — 外部 LLM で作った JavaScript を貼り付けて実行(Gemini 不使用)。

⚠ 入力されたコードは new Function でそのまま実行されます。信頼できないコードは実行しないでください。

Chat 3D

ChatGPT 等で生成した JavaScript を貼り付けて「実行」を押すと、シーンに反映されます。 コードには scene / THREE / CSG / targetMesh / setResult(mesh) が渡されます。
